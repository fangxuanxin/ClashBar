切换历史默认在本机记录控制器名称、模式、节点与分组名称、选择路径、观测时间和默认出口测速结果，保留最近 30 天。控制器历史身份由连接参数摘要生成，不在历史库保存明文口令或地址。最多保留 5 份每日恢复备份，备份可能包含更早的记录。可在「切换历史」暂停记录或清空所有记录和恢复备份。历史不包含访问域名或连接明细，不上传开发者服务器。删除控制器配置不会自动清除其历史，可另行清空。

Switch history locally records controller names, modes, node and group names, selection paths, observation times and default-exit latency test results for 30 days. Controller history identities use a digest of connection parameters; the history database does not store plaintext secrets or addresses. Up to five daily recovery backups may contain older records. Recording can be paused and all observations and recovery backups cleared in Switch History. History contains no visited domains or connection details and is not uploaded to the developer. Removing a controller configuration does not automatically delete its history.

ClashBar 是连接用户已有 Clash API 控制器的菜单栏工具，不提供代理服务、VPN 服务或订阅，不内置代理内核。

我们不运营收集应用数据的服务器，不在此版本中加入广告、分析或追踪 SDK，不向开发者上传控制器地址、口令、节点、网络活动或使用统计。

控制器名称、地址、口令保存在 Mac 上的应用沙盒中；口令以仅当前用户可读的 JSON 文件保存，并非加密保险库。界面偏好保存在本机 UserDefaults。应用读取节点名称、分组、模式、延迟和内核版本以展示状态。删除控制器可移除该配置；卸载应用不保证系统自动删除其容器，可另行删除应用容器中的数据。复制出口信息只在用户操作后写入系统剪贴板。

应用向用户配置的控制器发起 HTTP/HTTPS 请求，并携带对应口令。明文 HTTP 不加密地址与口令，请只在可信网络使用，远程连接优先使用 HTTPS。商店版可能探测本机 9090、9097 端口，不自动读取其他应用的配置或扫描网关。

ClashBar 不发起额外的节点或分组测速，仅读取已有内核健康检查的时间、结果和测试网址，按原时间去重保存。健康检查仍由用户的代理内核或既有脚本负责。旧版主动测速记录会保留并单独标识。节点地区根据节点或分组名称识别，不访问设备定位。仅本地网络连接需要时，macOS 可能请求本地网络权限；拒绝权限可能导致局域网控制器不可用。

应用更新由 Mac App Store 负责。用户主动打开项目支持页面后，由 GitHub 按其隐私政策处理网页访问。问题和隐私请求可通过 https://github.com/fangxuanxin/ClashBar/issues 联系，请勿在公开反馈中附带口令或私人配置。

ClashBar is a menu bar companion for an existing controller that exposes the Clash API. It does not provide a proxy service, VPN service, subscriptions or an embedded proxy engine.

We operate no server that collects app data. This version contains no advertising, analytics or tracking SDK. Controller addresses, secrets, nodes, network activity and usage statistics are not uploaded to the developer.

Controller names, addresses and secrets are stored in the app sandbox on your Mac. Secrets are stored in a JSON file readable only by the current user, not in an encrypted vault. Preferences use local UserDefaults. The app reads node names, groups, mode, latency and engine version to display status. Removing a controller deletes that saved entry. Uninstalling may leave container data behind; you can remove it separately. Exit information is copied to the system clipboard only at your request.

The app sends HTTP/HTTPS requests, including your configured secret, to your controller. HTTP does not encrypt the address or secret; use trusted networks and prefer HTTPS for remote access. The store version may probe local ports 9090 and 9097. It does not automatically read other apps’ configurations or scan the gateway.

ClashBar does not initiate node or group latency tests. It reads existing core health-check timestamps, results and test URLs, deduplicating samples by their original timestamp. Your core or existing scripts remain responsible for testing. Legacy active-test records are preserved and labeled separately. Region labels come from node or group names, not device location. macOS may request local network permission; denying it may prevent access to LAN controllers.

Updates are handled by the Mac App Store. Opening project support pages subjects web visits to GitHub’s privacy policy. Contact us at https://github.com/fangxuanxin/ClashBar/issues for support or privacy requests. Do not include secrets or private configurations in public issues.
